GOAL: Prove the operator can complete a minimal end-to-end assurance flow in Chrome — not a full Production AI replica or the full control catalog.

MINIMAL PATH (must work end-to-end):
1. Create System — add a small test system (a few assets is enough; architecture need not mirror Production AI).
2. Scope Controls — mark a small set of controls in-scope / out-of-scope (a handful, not ~100).
3. Assess — for those in-scope controls, set PRISMA scores, add simple text evidence where needed, and record at least one finding/gap when a score is weak.
4. Done — operator can see the system as assessed for that small scope (scores + finding visible).

CONSTRAINTS:
- Prototype only: no auth, no real DB, no middleware API.
- Stay in the existing graph + engine + React architecture.
- Prefer HITRUST-style scoring behavior when it conflicts with the engine.
- Do not ask for permission; keep iterating until this minimal path works with no blockers.

LOOP:
- Re-test the full minimal path after changes.
- Stop only when a user can finish steps 1–4 in Chrome without errors or missing UI.
